Funcionamiento del visor

¿Que tema representa tu visor 3D?

El proyecto representa un visor 3D educativo e interactivo. Permite explorar diferentes objetos tridimensionales y consultar informacion sobre cada uno de ellos.

¿Que objetos agregaste a la escena?

Se agregaron un cubo, una esfera, un cilindro, un cono, un toroide y un modelo externo en formato GLB.

¿Que información aparece cuando seleccionas un objeto?

El panel muestra el nombre del objeto, su tipo, una descripcion y un dato adicional relacionado con su funcion o caracteristica.

¿Como implementaste el raycasting?

Se utilizo la clase Raycaster de Three.js. Al hacer clic, se calcula la posicion del mouse sobre el canvas y se lanza un rayo desde la camara para detectar los objetos intersectados.

¿Que controles agregaste para modificar la escena?

Se agregaron controles para detener o activar la animacion, cambiar el color del cubo, ocultar o mostrar el modelo, modificar la intensidad de la luz y reiniciar la camara.

¿Que modelo .glb o .gltf utilizaste?

Se utilizó un modelo externo en formato GLB almacenado dentro de la carpeta models con el nombre modelo.glb.

¿Que parte del proyecto fue la mas difcil?

La parte mas dificil fue implementar correctamente el raycasting y la carga del modelo GLB, especialmente las rutas de los archivos y la interaccion entre el mouse y los objetos 3D.

¿Como podrias mejorar este visor si lo conectaras despues con PHP, FlightPHP y SQLite?

Se podria guardar la informacion de los objetos en una base de datos SQLite y utilizar PHP y FlightPHP para crear una API. De esta manera, el visor podria consultar dinamicamente los datos de cada objeto desde el servidor.
